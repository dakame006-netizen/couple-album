# Данияр и Кадиша — Фотоальбом

Спокойный минималистичный сайт-альбом в стиле хорошей фотокниги. Без лишнего визуального шума, рассчитан на сотни и тысячи фотографий, с автоматической раскладкой по хронологии (**Год → Месяц → День** и отсчётом **«день N»** с 12 января 2025 года).

## 🚀 Запуск

Внешние пакеты не требуются — используется встроенная в Node.js база `node:sqlite`:

```bash
cd /Users/daniar/.gemini/antigravity/scratch/couple-album
npm start
```

Откройте в браузере:
- На этом компьютере: **http://localhost:3000**
- С телефонов в домашней сети Wi-Fi: адрес выводится в терминале при запуске (`http://192.168.x.x:3000`)

## ✨ Как устроен альбом

- **Массовая загрузка (Drag & Drop или выбор пачкой):** можно перетащить в окно сразу 50–200 фотографий. Каждая фотография:
  1. Считывает точную дату и время съёмки из **EXIF** (`DateTimeOriginal`) прямо в браузере без сдвига часовых поясов.
  2. Проверяется по **SHA-256 хешу**, чтобы случайно не загрузить дубликаты.
  3. Сохраняется в трёх версиях:
     - `data/media/thumb/` — лёгкое превью (800px) для мгновенной прокрутки таймлайна
     - `data/media/full/` — веб-версия (2048px) для полноэкранного просмотра
     - `data/media/original/` — исходный файл без потерь (можно скачать из лайтбокса)
- **Хронология «Год → Месяц → День»:**
  - Внутри каждого дня фотографии автоматически выстраиваются в ровные журнальные ряды с сохранением пропорций каждого кадра.
  - У каждого дня отображается дата, день недели и номер дня с **12 января 2025**.
  - Каждому дню можно дать короткое название прямо на странице (например, *«Поездка в горы»* или *«Выходные вместе»*) — оно сохраняется автоматически.
- **«В этот день»:** если есть снимки, сделанные в сегодняшнюю дату в прошлые годы, они автоматически появляются вверху страницы.
- **Поиск и «Случайный кадр»:** быстрый фильтр по названиям дней, подписям к фото, месяцам и датам, а также кнопка случайного воспоминания.
- **Простой бэкап:** вся база (`album.db`) и все фотографии лежат в одной папке `data/` — достаточно скопировать её на внешний диск или в облако.
